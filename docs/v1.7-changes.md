# Release 1.7.0: acquisition-only channel experiments

The report introduces channel holdouts immediately after the business/journey section, lists acquisition results and iCAC descriptively, and returns to them in the finale after forecasting contribution LTV. Experiments have one role: acquisition-channel decisions.

Dataset 5.0/schema 3.0 removes the 1,000 legacy assigned prospects, 188 linked buyers and all their linked periods, transactions, events and feedback, plus six test-spending rows. All retained raw rows preserve their original bytes and order. The operational panel now contains 5,703 customers. Old sources and receipts remain recoverable in earlier Git tags; they are not current inputs.

The replacement `channel_holdouts.csv` contains eight arm summaries for four disjoint channel-by-need tests. It has assignment totals, first-acquisition counts and acquisition spending, with no person join, experimental revenue or retention. These separate pilot counts and costs cannot affect cohort accounting, diagnostics or model fitting. Frozen inputs and full analytical reproduction are public; no private future outcomes or generator are used.

Saved SQL computes `channel_cac.csv`, using all assigned prospects, scaled controls and media plus other incremental acquisition costs. The former contribution effects, test-program pooling, cohort experiment sensitivities and scattered experimental discussion are removed.

`channel_value_decision.csv` joins each result to the matching July 2025 operational cohort's twelve-receipt contribution value before CAC. Value less iCAC and program net value are planning projections under explicit assumptions about additional customers' value and unchanged value for would-be buyers. Forecast shares remain visible; acquisition uncertainty is in the appendix. Historical blended CAC remains the accounting measure for the matching cohort panel.

Both models must be freshly fitted to the revised operational panel. The release receipt distinguishes new inference, report reproduction, tests, visual review and public ZIP validation. Cover, style, citations, segmentation objective, original-customer denominators and the company-economics/model section order are preserved. Both skills and the reproducibility guide carry the revised contract.

The optional challenge grid and baseline forecasts use the revised population. The archived private-answer commitment is preserved as historical provenance and is not certified for dataset 5.0. Before future scoring, the instructor must reconcile the answer file to the released customer IDs, preserving their existing realized outcomes. No private future outcomes were read or regenerated for this release; see the challenge contract.
