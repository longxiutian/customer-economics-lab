# Executed query example

`query.sql` is the exact read-only question executed in the guided check.
`result.csv` is its complete result, and `manifest.json` preserves the original
execution receipt and source hashes.

The receipt also lists `registration.sql`, generated by the helper to register
local source files. That host-specific file contains absolute paths and is not
bundled in this public excerpt. After stage 3, reproduce the question with:

```text
uv run --frozen python lab.py query --sql-file examples/reference/queries/5e7b35de6e014a68af905da6baeff737/query.sql
```

The fresh query folder contains all four artifacts, including its locally
appropriate registration script. This command does not advance the stage.
